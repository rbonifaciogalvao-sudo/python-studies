* **Caminho:** `algoritmos/elementos_unicos.py`
* **Descrição:** Script que recebe uma lista com números repetidos, filtra os valores duplicados usando `set()`, conta a quantidade de elementos e soma seus valores.
* **Exemplo de Execução:**
  ```python
  dados = [3, 1, 3, 2, 1]
  # Remove duplicados -> {1, 2, 3}
  # Quantidade (3) + Soma (6) = 9
  ```
